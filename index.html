Award overview

Post-processing decompressed scientific data

Error-bounded lossy compression can reduce data movement and storage, while decompression artifacts can affect downstream numerical and topological analysis. This program investigates neural methods that operate on fields after decompression, with complementary 2D temporal and 3D topology-oriented directions.

The projects describe implemented research software and method boundaries. Their evaluation remains pending; this portfolio does not present benchmark, generalization, or performance claims.

Project 01

DenseTopo-UNet

How can a neural post-processing model edit one decompressed 3D scalar field while reserving reference and topology information for training supervision?

DenseTopo-UNet takes one decompressed scalar volume at inference. Its gated residual 3D U-Net predicts a signed correction and spatial gate; reference values and topology labels are used during training, not as inference inputs.

  1. One decompressed volume
  2. Gated residual 3D U-Net
  3. Tiled restored volume
  • Accepts one decompressed scalar channel at inference.
  • Uses correction and gate heads to form a bounded edit relative to the decompressed value.
  • Uses numerical and local topology-derived terms during training.
  • Uses context tiling that writes every output voxel once.

Project 02

PTU-Net

How can temporal context guide reconstruction of a decompressed 2D center field?

PTU-Net forms center-anchored features from three temporally adjacent decompressed fields. It combines an adaptive temporal baseline, patch-transformer correction, and a gated U-Net refinement before reconstructing a full field from overlapping patches.

  1. Three adjacent decompressed fields
  2. Temporal baseline and transformer correction
  3. Gated refinement and full-field reconstruction
  • Builds center, previous-minus-center, and next-minus-center input features.
  • Combines adaptive spatial and global temporal weights for its baseline.
  • Applies a patch-transformer correction followed by gated U-Net refinement.
  • Combines overlapping patch predictions with Gaussian weighting across the full field.
